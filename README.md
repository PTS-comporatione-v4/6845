# CICADA 6845 // TEST 04

Fáza 2 pokračuje. Prvá skutočná šifra.

## Čo ťa čaká

Vigenère s kľúčom. Dva texty, len jeden je pravý.

**CESTA A** — prvý text:

`mkm weibp hvzhjloe, qaxgt zzr geysrh seemny.`

**CESTA B** — druhý text:

`ef qp sly eksxrgu, lrzt syo osh pjdvbkb os gpt.`

Lúšti sa na [cryptii.com](https://cryptii.com) → Vigenère cipher
(Standard, kľúč `cryptiypts`, Autokey, a–z, Ignore case, Include, DECODE).
Odpoveď je POSLEDNÉ slovo dekódovaného textu.
